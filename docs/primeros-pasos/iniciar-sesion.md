# Iniciar sesión e instalar

La Bull Army Terminal es exclusiva para **miembros VIP**. Para usarla necesitás el usuario y la contraseña que te entrega Bull Army.

![Pantalla de acceso](../.gitbook/assets/login.png)

## Entrar

1. Abrí **https://camilolwi-oss.github.io/bull-army-terminal/**
2. Escribí tu **usuario** (no importan mayúsculas o minúsculas) y tu **contraseña** (esta sí distingue mayúsculas).
3. Tocá **Entrar**.

La sesión queda guardada en ese navegador: la próxima vez entrás directo, sin volver a escribir los datos.

{% hint style="info" %}
Con el botón **Ver** podés mostrar la contraseña mientras la escribís, para comprobar que esté bien.
{% endhint %}

## Cerrar sesión

En el menú lateral, abajo, tocá **Salir · tu usuario**. Pasando el mouse por encima ves hasta qué fecha tenés acceso.

Cerrá sesión si usaste una computadora que no es tuya.

## Vencimiento

Cada acceso tiene una **fecha de vencimiento**. Cuando llega, la terminal te pide volver a entrar y muestra un aviso para renovarlo con Bull Army.

Si tu acceso fue dado de baja, la sesión se cierra sola: la terminal lo revisa al entrar, cada 10 minutos y cada vez que volvés a la pestaña.

## Mensajes posibles

| Mensaje | Qué pasa |
|---|---|
| *Usuario o contraseña incorrectos* | Revisá los datos. Después de 5 intentos fallidos hay que esperar 30 segundos. |
| *Tu acceso venció el …* | Llegó la fecha de vencimiento. Contactá a Bull Army para renovarlo. |
| *Tu acceso fue dado de baja* | El acceso fue revocado. Contactá a Bull Army si creés que es un error. |
| *No se pudo verificar el acceso* | Problema de conexión. Revisá internet y recargá la página. |

## Instalar como app

La terminal se puede instalar como una aplicación: queda con el ícono de Bull Army en tu escritorio o pantalla de inicio y se abre en su propia ventana, sin barra del navegador.

| Dispositivo | Cómo |
|---|---|
| **Computadora** (Chrome o Edge) | Tocá el ícono de instalar en la barra de direcciones (una pantalla con una flecha) → **Instalar**. |
| **Android** (Chrome) | Menú **⋮** → **Instalar app** o **Agregar a la pantalla principal**. |
| **iPhone / iPad** (Safari) | Botón **Compartir** → **Agregar a inicio**. |

La app instalada pide el mismo login y respeta el vencimiento. Necesita internet: los datos son en vivo.
