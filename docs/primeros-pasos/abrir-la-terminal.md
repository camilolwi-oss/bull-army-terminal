# Abrir la terminal

Hay dos formas de usarla. Para operar, la primera alcanza.

## 1. Desde la web (recomendado)

Entrá a:

**https://camilolwi-oss.github.io/bull-army-terminal/**

Se actualiza sola cada vez que se publica una versión nueva. Guardala en favoritos o [instalala como app](iniciar-sesion.md).

Necesitás tu **usuario y contraseña VIP**: ver [Iniciar sesión e instalar](iniciar-sesion.md).

## 2. Desde el código (para desarrollar)

Necesitás [Node.js](https://nodejs.org) 18 o superior y [Git](https://git-scm.com).

```bash
git clone https://github.com/camilolwi-oss/bull-army-terminal.git
cd bull-army-terminal
npm run dev
```

Abrí <http://localhost:5173>. Más detalles en [Modificar el código](../desarrollo/modificar-el-codigo.md).

## Requisitos

- Un navegador actual (Chrome, Edge, Safari o Firefox).
- Conexión a internet sin bloqueos hacia `api.hyperliquid.xyz`. Algunas VPN, firewalls corporativos o bloqueadores de anuncios la cortan; en ese caso la terminal entra en [modo demo](../como-funciona/modo-demo.md).
- Funciona en el celular, aunque el gráfico del Indicador se aprovecha mejor en una pantalla grande.
